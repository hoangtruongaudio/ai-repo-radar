AI REPO RADAR V3.1.1 — SỬA BỘ LỌC TỰ ĐỘNG

1. Sao lưu index.html hiện tại.
2. Thay nội dung index.html của GitHub repo hoangtruongaudio/ai-repo-radar bằng file index.html này.
3. Commit changes vào main; kiểm tra GitHub Actions pages build and deployment thành công.
4. Mở website, Ctrl+F5. Chọn Học tập & giáo dục -> Quản lý kiến thức, kết quả sẽ tự làm mới.
5. Không cần thay worker.js, GROQ_API_KEY, RADAR_ACCESS_TOKEN.

LƯU Ý: Lọc theo ngành hoặc nhóm dùng từ khóa bao quát, còn chọn nhu cầu cụ thể dùng từ khóa chuyên sâu; số sao là tổng sao chứ không phải xu hướng tuần. API GitHub có thể giới hạn tốc độ tìm kiếm.

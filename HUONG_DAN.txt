AI REPO RADAR V3.1 — HƯỚNG DẪN

1. Sao lưu file index.html trên GitHub trước khi sửa.
2. Thay toàn bộ index.html trên GitHub branch main bằng index.html bản V3.1.
3. Commit changes, kiểm tra GitHub Actions > pages build and deployment thành công.
4. Mở website và vào Xếp hạng Repo; có bộ lọc 3 cấp Ngành nghề → Nhóm công việc → Nhu cầu.
5. Chọn nhu cầu rồi nhấn Tìm theo nhu cầu. Có thể sửa truy vấn, lọc số sao, forks, cập nhật.
6. Không cần thay Cloudflare Worker/GROQ_API_KEY nếu đã cấu hình phiên bản dùng Groq.

GIỚI HẠN
- Đây là bản cải tiến bộ lọc; chưa phải đo lường đạt 9.0/10.
- Repo được tìm từ GitHub Search bằng từ khóa; không có chứng thực tự động rằng repo làm được mọi tính năng.
- Trending tăng sao thực tế chỉ đo khi có mốc dữ liệu cục bộ ở các thời điểm tương ứng.
- Chưa thử trình duyệt/iPhone thật hoặc Groq API của bạn.
